# Security policy

Do not report a vulnerability by opening a public benchmark case or attaching customer text to a
public issue. Use the repository owner's private security-reporting channel.

The triage service is recommendation-only: it must not receive credentials capable of refunds,
account mutation, or workflow execution. Production deployments must run as a non-root user, pin
model and policy artifacts, limit request size and concurrency, and avoid raw conversation logs by
default.

Supported security fixes are applied to the latest minor release. Until a private reporting address
is configured, contact the project owner through the private channel used to distribute hidden
benchmark assets.
